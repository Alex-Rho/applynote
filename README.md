# Applynote — 지원 기록

한국어 개인 채용 지원 관리 사이트의 소스입니다. 아직 게시되지 않았습니다.

## 작성한 기능
- 회사, 포지션, 지원 플랫폼, 공고 링크와 지원일 입력 및 수정
- 채용 요구사항, 기대 역할, 면접 준비 메모 저장 API
- 지원 완료 / 서류 통과 / 1차 면접 / 2차·최종 면접 / 오퍼 / 종료 보드
- 면접 날짜·시간, 단계 변경 이력
- Cloudflare D1을 사용하는 영구 저장 구조
- 모바일 화면, 로딩·오류·빈 상태

공고 내용은 직접 붙여넣는 방식이며 LinkedIn 자동 연동은 포함하지 않습니다.
현재 설계는 소유자만 접근 가능한 개인 사이트 전용입니다. 다중 사용자로 공개하려면 사용자별 인증과 데이터 분리가 필요합니다.

## 검증 상태 및 남은 작업
TypeScript 검사(`pnpm exec tsc --noEmit`)는 통과했습니다.
현재 환경에서 하위 프로세스 실행이 `spawn EPERM`으로 차단되어 개발 서버, Drizzle 마이그레이션 생성, 프로덕션 빌드를 완료하지 못했습니다. 따라서 실제 저장 동작과 게시된 화면은 검증하지 못했습니다.

일반 개발 환경에서 다음을 진행해야 합니다.
1. Node.js 22.13 이상과 pnpm으로 의존성 설치: `pnpm install`
2. DB 마이그레이션 생성: `pnpm db:generate` (생성된 SQL 검토 필요)
3. 로컬 D1에 생성된 마이그레이션을 적용한 뒤 `pnpm dev` 실행
4. 기록 추가 → 새로고침 → 수정 및 단계 변경 → 이력 확인, 입력 오류 및 저장 오류 확인
5. `pnpm build` 성공 후 Sites에 소스를 저장하고 소유자 전용으로 게시

`.openai/hosting.json`에는 이미 등록된 Sites 프로젝트가 들어 있습니다. 같은 사이트를 이어서 사용하고 새 프로젝트를 중복 생성하지 마세요. 소스에는 인증 토큰을 포함하지 않았습니다.

## Windows에서 실행
Node.js 24 LTS를 설치한 뒤 새 PowerShell 창을 여세요.
압축 파일을 풀고 package.json이 있는 applynote 폴더에서 터미널을 여세요.

```powershell
npm.cmd install -g pnpm@11.19.0
pnpm.cmd install
pnpm.cmd db:generate
pnpm.cmd db:local
pnpm.cmd dev
```

명령은 한 줄씩 실행하고 오류가 나면 다음 단계로 넘어가지 마세요.
마이그레이션 적용 확인이 나오면 Y를 선택하세요.
개발 서버가 표시하는 Local 주소를 브라우저에서 여세요. 종료는 Ctrl+C입니다.
두 번째부터는 같은 폴더에서 pnpm.cmd dev만 실행하면 됩니다.
로컬 데이터는 이 프로젝트의 .wrangler 폴더에 저장되므로 이 폴더를 삭제하지 마세요.
이 절차는 실행 환경의 권한 문제 때문에 아직 끝까지 검증하지 못했습니다.
