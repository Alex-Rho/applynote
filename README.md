# Applynote · 지원 기록

회사와 포지션, 공고 링크, 채용 요구사항, 기대 역할, 인터뷰 단계와 메모를 관리하는 개인용 앱입니다.

## 저장과 백업
- 기록은 현재 브라우저의 localStorage에만 저장합니다. 지원 기록을 GitHub나 외부 서버로 전송하지 않습니다.
- 같은 기기와 같은 브라우저, 같은 사이트 주소에서 다시 열면 이어서 사용할 수 있습니다.
- 브라우저 데이터 삭제, 시크릿 모드 종료, 기기 변경에 대비해 **백업 내보내기**를 사용하세요.
- **백업 가져오기**는 기존 기록을 유지하면서 새로운 기록만 추가합니다. 동일 ID의 기존 기록을 덮어쓰지 않습니다.
- localhost와 GitHub Pages는 별개의 저장 공간입니다. 옮길 때 백업을 내보낸 뒤 새 주소에서 가져오세요.
- 이전 서버 버전의 D1 데이터는 자동 변환하지 않으며 기존 `.wrangler` 폴더는 보존합니다.

## 실행
Node.js 24와 pnpm 11.19.0에서:

```powershell
pnpm.cmd install
pnpm.cmd dev
```

터미널에 표시되는 Local 주소를 여세요.

## GitHub Pages 배포

```powershell
pnpm.cmd build
```

생성된 `docs/` 폴더가 배포 결과물입니다. GitHub 저장소의 Settings → Pages에서 **Deploy from a branch**, **main**, **/docs**를 선택합니다.
소스를 수정하면 다시 빌드하고 변경된 소스와 `docs/`를 함께 커밋하세요.
현재 GitHub 플랜에서는 Pages를 켜려면 공개 저장소가 필요합니다. 공개 전환은 소유자가 결정해야 합니다.
사이트 화면과 코드는 공개될 수 있지만 방문자의 기록은 각자 브라우저에 저장됩니다.

## 검증
- 프로덕션 정적 빌드 성공
- TypeScript 검사 통과
- 저장 후 재읽기, 단계 이력, 백업 왕복, 중복 보존, 잘못된 백업 거부, 저장 공간 오류 처리 검사 통과

이 저장소에는 이전 서버 버전의 설정과 API 소스도 남아 있습니다. Pages에 게시하는 `docs/` 결과물에는 서버 API, D1 데이터 또는 인증 토큰이 포함되지 않습니다.
